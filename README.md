# GameGlot Translator — обновления

Здесь лежит `manifest.json` — служебный файл, по которому программа **GameGlot Translator** узнаёт о новых версиях.

**Скачать программу:** https://boosty.to/gameglot

GameGlot Translator переводит игры на Godot и Ren'Py в один клик: выбираете .exe игры, язык — и через минуту играете на своём языке. 35 языков, картинки в переписках остаются на месте, оригинал игры не меняется.
